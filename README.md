# Weather Forecast & Alert Application

## Overview
This project is a Python-based Weather Forecast & Alert Application that fetches live weather data using weather APIs and generates alerts for rain, heat, humidity, and bad weather conditions.

## Features
- Live weather fetching
- API integration
- Weather alerts
- CSV report generation
- Weather visualization
- Streamlit dashboard

## Technologies Used
- Python
- Requests
- Pandas
- Matplotlib
- Streamlit
- OpenWeatherMap API
